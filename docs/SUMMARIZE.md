## Code Quality Observations

**Strengths:**
- Clean separation of concerns; protocol, model, engine, data, and UI layers do not leak into each other.
- Coroutines used consistently (`channelFlow`, `withContext(Dispatchers.IO)`).
- SQLite uses parameterized queries (no string concatenation in SQL).
- No `console.log`, no TODOs, no dead code observed.

**Minor issues to fix:**
1. `MainActivity.shareConversation()` builds Markdown on the coroutine dispatcher but calls `startActivity()` from within `lifecycleScope.launch` — this is fine on Android (main-scope-safe), but it would be cleaner to collect the string on IO and launch the intent on the main thread.
2. `EncryptedPreferences.create()` creates a new `MasterKey` each time `Settings.get()` is called, but caches the `Settings` instance statically, so the key is created once per app process. Acceptable.
3. `formatTime()` in `ConversationListActivity` is a top-level private function; fine, but could be a utility.

## Security Analysis (M2+M3+M4)

| Threat | Mitigation | Residual Risk |
|--------|-----------|---------------|
| API key exfiltration via backup | `backup_rules.xml` + `data_extraction_rules.xml` exclude prefs | None meaningful |
| Key exfiltration via rooted device | Key in Android Keystore (device-bound) | Key is accessible if device is fully compromised/rooted |
| Cleartext traffic | `usesCleartextTraffic="false"` + network security config | None for listed domains |
| MITM on MCP/server connections | HTTPS enforced | No certificate pinning (server cert not pinned) |
| Tool exfiltration | Per-call approval dialog with server name + args | User must read and approve; no silent tool execution |

**Recommendation:** Add certificate pinning for `api.hcnsec.cn` and other production provider domains before shipping.

## Recommendations for M5

1. **Certificate pinning** for production provider domains.
2. **History trimming** — already capped via `historyLimit` (default 40), but UI slider already exposed in Settings. Consider automatic summarization for very long conversations.
3. **Message search** — SQLite full-text search on `messages.content`.
4. **Per-server confirmation prompt default** — already defaults to `true`; consider remembering per-server trust permanently (currently session-only).
5. **Export improvements** — include tool-call reasoning traces and timestamps in Markdown export.
6. **Migration safety** — document that clearing app data deletes the encrypted key and requires re-entering the API key.
